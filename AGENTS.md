# AGENTS.md - Dr. Wau

This file contains project-specific rules only. All global Codex rules remain applicable.

## Scope

This repository supports the native Dr. Wau app in the repository root.

Keep work limited to:

- read-only Homey health analysis
- battery-device discovery and silence evaluation
- notification and repeat-suppression logic
- finding management and local settings
- integrated configuration backup, scheduled destinations, and explicit selective restore
- Homey Flow cards exposed by the app
- app manifests, settings UI, tests, validation, and documentation

Do not reintroduce the removed Advanced Flow watchdog tooling as a second supported implementation.

## Homey safety

Homey is production. Do not install, run, or publish the app without explicit authorization. Prefer static validation and local builds. Do not trigger unrelated device actions, locks, charging, alarms, heating, or other real-world behavior while testing.

## App behavior

- Keep health analysis read-only.
- Backup creation is read-only; restore writes require explicit selection and confirmation.
- Retain the Backup Center MIT license and contributor notices for imported code.
- Distinguish numeric battery values, battery alarms, unavailable data, unsupported devices, and stale or missing timestamps.
- Do not fabricate a battery percentage or claim a specific cause for communication silence.
- Avoid notification spam and persist delivery suppression only after successful delivery.
- Keep owner APIs private and preserve existing settings across compatible updates.

## Source and generated files

- Edit `.homeycompose/app.json`; `app.json` is generated by the Homey CLI and must remain consistent.
- Keep generated builds, dependencies, reports, device inventories, logs, backups, credentials, and live Homey exports out of Git.
- Do not commit Homey tokens, recipient IDs, production object IDs, or private device names.

## Validation

After meaningful app changes, run from the repository root:

```powershell
npm.cmd ci
npm.cmd test
npm.cmd run validate:publish
npx.cmd homey app build
```

State clearly whether validation was local or performed against a live Homey.
